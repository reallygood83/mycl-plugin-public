# 생기부 교과 세특

공식 표기는 마이클 / MyClass, 도메인은 mycl.io 다. 비공개 내부용이다.

중학·고등 교과 세특은 별도 도구가 아니다. 이 페이지의 학교급에서 초등, 중학, 고등을 고른다. seq=82 페이지는 열지 않는다. 바로 46으로 넘어간다.

칸은 머리글 문구로 찾지 않는다. `studentRecords.subjectComment.columns` 의 열 순서를 쓴다. 왼쪽부터 번호, 가명, 수행평가, 누가기록, 평가 수준, AI 생성 문장, 최종 문장이다. 「학생」과 「선생님께서」는 머리글일 뿐 셀렉터가 아니다.

## 절대 규칙

- 「저장」, 「나이스 반영하기 →」, 「유사도 검사」는 누르지 않는다. 이 페이지에는 「일괄 등록」과 「양식 다운」이 없다.
- 「전체 붙여넣기」와 「내려받기」는 사용자가 요청할 때만 누른다.
- 학생 실명을 넣지 않는다. 번호나 가명을 권한다.
- 표 칸은 fill 또는 붙여넣기로 넣고 다시 읽는다.
- 교과와 평가 수준은 필수다. 평가 수준은 5자까지다.

## 순서

1. `https://mycl.io/tool/create-no-modal?seq=46` 을 연다.
2. 학교급, 학년, 반, 교과를 고른다. 교과는 국어, 수학, 통합교과다.
3. 행이 모자라면 「+ 신규 학생 추가」로 늘린다.
4. 번호, 가명, 수행평가, 누가기록, 평가 수준을 채운다.
5. 「전체 생성」을 누르고, 학생별 AI 생성 문장과 Bytes 를 JSON으로 보고한다.
6. 하단 안내를 결과에 포함한다. 「※ 이용중인 플랜(유료/무료)에 따라 일부 문장 완성도에 차이가 발생할 수 있습니다. 생성 결과는 반드시 검토 후 활용해 주세요.」
