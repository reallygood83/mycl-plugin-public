# 마이클 가정통신문

Codex 한 줄 설치에서는 `mycl-browser` 도구를 쓰고, 보조 파일과 스크립트는 `~/.local/share/mycl-plugin`을 기준으로 읽거나 실행한다. 수동 설치는 클론 폴더를 기준으로 삼는다.

먼저 `mycl-login-check` 를 따른다. 로그인 실패면 문서를 만들지 않는다.

문구의 기준 파일은 `scripts/selectors.json` 이다. 보이는 글자와 다르면 파일을 고친 뒤 진행하고, 모르는 문구는 TODO 로 남겨 둔다.

## 절대 규칙

- 「저장」은 절대 누르지 않는다. 문서함 저장 창은 전체 공개가 기본이다. 저장 창이 열리면 「취소」나 「닫기」만 누른다. 그 버튼이 없으면 멈추고 사용자에게 알린다.
- 「나이스 반영하기 →」는 누르지 않는다.
- 공유, 발송, 결제, 구독 변경, 가입, 삭제는 사용자가 대화에서 확인한 뒤에만 한다.
- `browser_click` 전에 `node scripts/check-click.mjs "접근 가능한 이름"` 을 실행한다. 0이 아니면 누르지 않는다. 저장과 나이스 반영은 `--confirmed` 로도 허용되지 않는다. 통과해도 이 절차에 적힌 컨트롤만 누른다.
- 학생 실명, 주민등록번호, 계좌번호처럼 민감한 값은 넣지 않는다. 요청에 있으면 학년·반처럼 식별되지 않는 표현으로 바꿔 달라고 하고 중단한다.
- 비밀번호, 세션, storageState, 쿠키, 프로필, 내려받은 파일을 커밋하지 않는다. `browser_storage_state` 를 쓰지 않는다.
- `browser_run_code_unsafe` 는 쓰지 않는다.

## 폼

주소는 `https://mycl.io/tool/create?seq=6` 이다.

1. 요청에서 학교명, 제목, 날짜, 장소, 회신 필요 여부를 뽑는다. 학교명이 없으면 묻는다. 시간이나 준비물처럼 작은 빈칸은 흔한 값으로 채우고, 결과에서 어떤 값을 넣었는지 한 줄로 알린다.
2. 칸은 `scripts/selectors.json` 의 문구로 찾는다. 유형은 라디오 「신청」(기본)과 「안내」다. 제목은 50자, 인사말은 100자, 전달사항과 기타사항은 1,000자다. 넣기 전에 글자 수를 센다. 넘으면 줄이거나 묻는다.
3. 한글은 `browser_type` 으로 넣되 `slowly` 는 켜지 않는다. 한 번에 들어가야 한다. 글자가 깨지면 `browser_drop` 으로 `text/plain` 을 그 칸에 붙여넣는다.
4. 폼에는 템플릿 드롭다운과 토글이 없다. 생성 뒤 결과 머리말의 「선택 템플릿」 기본값은 「기본 템플릿 1」이다. 사용자가 다른 템플릿을 말하기 전에는 그대로 둔다.
5. 다국어 QR 은 체크박스다. 영어, 중국어, 베트남어, 태국어, 일본어, 캄보디아어, 필리핀어, 몽골어 가운데 사용자가 말한 언어만 켠다. 추가 언어 칸 placeholder 는 「추가 언어 직접 입력 (쉼표(,)로 구분)」이다.
6. 개인정보 제공 동의는 라디오 「포함」과 「미포함」이고 기본은 「미포함」이다. 사용자가 포함을 요청할 때만 「포함」을 고른다.
7. 유형은 사용자가 「안내」를 말하면 그 라디오를 고른다. 말하지 않으면 「신청」을 유지한다.
8. `node scripts/check-click.mjs "자동 생성"` 이 허용하면 「자동 생성」을 누른다. 생성된 뒤에는 버튼 문구가 「재생성」이다.
9. 주소는 같은 페이지에서 `/tool/create?seq=6&librarySeq=N` 으로 바뀐다. `/v2/edit` 로 자동 이동하지 않는다. 미리보기가 몇 초 뒤에 나온다. 편집이나 내려받기 전에 기다린다. 바뀌지 않으면 저장 버튼을 누르지 말고 멈춘다.

## 찾기와 바꾸기

학교명과 연락처를 바꾸려면 `https://mycl.io/v2/edit?seq=6&librarySeq=N` 으로 직접 가거나, 접근성 이름 「문서 편집」인 「편집」을 누른다. 머리글과 서명에는 계정 기본 학교가 들어간다. 확인된 기본 문구는 박달초등학교, 교무실·행정실 02-3442-7783, FAX 02-3442-7793, 서명 `박달초등학교장 [직인생략]` 이다. 계정 학교가 이와 다르면 화면에 실제로 있는 학교명을 바꾼다.

1. 머리글과 서명 텍스트를 읽는다.
2. 표준 입력으로 그 텍스트를 넘겨 계획을 만든다.

```bash
node scripts/plan-replacements.mjs --school "사용자가 준 학교명" --phone "전화번호" --fax "팩스" <<'EOF'
머리글과 서명 텍스트
EOF
```

전화나 팩스를 받지 못했으면 그 옵션을 빼거나 빈 문자열로 둔다. 스크립트는 기본 번호를 지우고, 지웠다고 notes 에 남긴다. 없는 번호를 만들어 넣지 않는다.

3. `pairs` 의 각 항목마다, `Replace All` 이 안 보이면 툴바 「Replace」를 누른다. 「Find」 버튼도 있지만 바꾸기는 Replace 탭이다. 창 제목은 「Find and Replace」다.
4. 칸 라벨은 「Find what:」와 「Replace with:」다. Search 는 「Whole Document」로 둔다. Match case 같은 체크박스는 켜지 않는다. 마지막 체크박스 문구는 사이트의 오타 그대로 `Ignore white-space charcters` 다.
5. 찾기 칸이 비어 있으면 「Find Next」는 비활성이다. `node scripts/check-click.mjs "Replace All"` 뒤에 `Replace All` 을 누른다.
6. `N items have been changed.` 가 보여야 한다. N 이 0이면 그 문자열은 문서에 없었던 것이다. 성공이라고 말하지 않는다.
7. 학교명을 바꾸면 서명 `OO초등학교장 [직인생략]` 의 학교명도 같이 바뀐다. 머리글 학교, 전화, 팩스, 서명을 다시 읽고 요청과 맞는지 확인한다.
8. 이 단계에서 「저장」(접근성 이름 「문서 저장」)과 「나이스 반영하기」가 보여도 누르지 않는다. 「저장」을 눌러 「저장하기」 창이 뜨면 공개 범위 기본값은 「전체 공개」다. `node scripts/check-click.mjs "취소"` 뒤에 「취소」를 누른다. X 버튼의 접근성 이름은 「닫기」다. 창의 「저장」은 누르지 않는다.

## 내려받기

메뉴 항목은 정확히 「HWP」와 「PDF」다. 화면의 파일명은 `<제목>.hwp` 로 보인다.

1. `node scripts/check-click.mjs "내려받기 옵션 열기"` 뒤에 그 버튼(보이는 글자는 「내려받기」)을 누른다.
2. 메뉴에 보이는 문구를 넘긴다.

```bash
node scripts/pick-download.mjs "HWP" "PDF"
```

3. 「HWP」를 우선 고르고, 없으면 「PDF」를 고른다.
4. 고른 문구로 `check-click` 을 다시 실행하고, 허용될 때만 그 항목을 누른다.
5. Playwright MCP 가 알려 주는 받은 파일 경로를 `./out` 으로 옮긴다. HWP 가 없으면 PDF 를 남긴다.
6. 받은 파일을 점검한다. 기본 학교명은 `selectors.json` 의 박달초등학교이고, 사용자가 다른 계정 학교를 말하면 `--school` 로 바꾼다. 학생 실명처럼 남으면 안 되는 말은 `--forbid` 로 반복한다.

```bash
node scripts/check-download.mjs ./out/받은파일.hwp --school "박달초등학교" --forbid "남기면 안 되는 말"
```

결과가 `ok: false` 이거나 종료 코드가 1이면 파일에 계정 기본 학교명이나 금지어가 남은 것이다. 채팅에 무엇을 찾았는지 알리고, 바꾸기가 더 필요한지 본다. `ok: true` 일 때만 점검을 통과했다고 말한다.
7. 채팅에 파일 경로, 넣은 기본값, 비운 연락처, 점검 결과, 문서함에 저장하지 않았다는 사실을 알린다.
