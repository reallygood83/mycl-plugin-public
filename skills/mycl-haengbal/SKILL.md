# 생기부 행발

공식 표기는 마이클 / MyClass, 도메인은 mycl.io 다. 비공개 내부용이다.

문구와 열 순서는 `scripts/selectors.json` 의 `studentRecords.haengbal` 이다. 학생 열 머리글이나 「선생님이」 같은 문장으로 칸을 찾지 않는다. 표의 칸은 왼쪽부터 번호, 가명, 누가기록, AI 생성 문장, 최종 문장이다.

## 절대 규칙

- 「저장」, 「나이스 반영하기 →」, 「일괄 등록」, 「유사도 검사」는 누르지 않는다. `check-click` 이 거절한다.
- 「전체 붙여넣기」와 「내려받기」는 사용자가 요청할 때만 `--confirmed` 로 누른다.
- 학생 실명을 넣지 않는다. 번호나 가명을 쓰라고 안내한다.
- 표 칸은 타이핑하지 않는다. `fill` 또는 붙여넣기로 넣고, 넣은 값을 다시 읽는다.
- seq=107 페이지는 열지 않는다. 바로 108로 넘어간다.

## 순서

1. `https://mycl.io/tool/create-no-modal?seq=108&levelSelect=1` 을 연다.
2. 학교급, 학년, 반을 고른다. 학교급은 유치원, 초등, 중학, 고등이다.
3. 기본 행은 5개다. 더 필요하면 추가 칸에 수를 넣고 「+ 신규 학생 추가」를 누른다. 「현재 등록된 학생 수 : N명」을 확인한다.
4. 각 행의 번호, 가명, 누가기록을 채운다. 누가기록은 필수이고 줄바꿈이 항목 구분이다. 번호는 5자까지다.
5. 「전체 생성」을 누른다. 결과는 같은 표의 AI 생성 문장 칸과 Bytes 다.
6. 학생별 번호, 가명, 문장, Bytes 를 JSON으로 보고한다. 하단 안내를 함께 적는다. 「※ 이용중인 플랜(유료/무료)에 따라 일부 문장 완성도에 차이가 발생할 수 있습니다. 생성 결과는 반드시 검토 후 활용해 주세요.」
7. 데이터가 없을 때 「내려받기」는 "다운로드할 유효한 학생 데이터가 없습니다." 경고를 띄운다.
